# Olshem — обучение стереометрии (10–11 классы, Казахстан)

**Репозиторий:** https://github.com/kenessaryanar/Olshem

Офлайн-ориентированное PWA: интерактивная 3D-сцена, геометрическое ядро, трёхъязычный интерфейс (kk/ru/en), локальные подсказки.
**Статус: ранний прототип, не готов к использованию в классе.** Подробности в `docs/STATUS.md`.

## Запуск
```
npm ci
npm run dev        # разработка
npm run check      # типы + тесты
npm run build && npm run preview
npm run e2e        # Playwright (нужен: npx playwright install chromium)
```
## Развёртывание на Vercel
Импортируйте репозиторий; Framework Preset — Vite, Build — `npm run build`, Output — `dist`. Переменные окружения для текущей версии не нужны. Серверных функций пока нет.

## Восстановление
Данные хранятся в IndexedDB браузера (`olshem`). Очистка данных сайта удаляет прогресс: экспорт и серверная синхронизация пока не реализованы. При ошибке сохранения интерфейс показывает статус «Ошибка сохранения».
